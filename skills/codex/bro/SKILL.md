# Bro

Rewrite the previous assistant response so it sounds like one person explaining it plainly to another.

- Keep the original meaning, commitments, warnings, uncertainty, citations, and important limits.
- Remove jargon when a common word works. Briefly explain any technical term that must remain.
- Cut process narration, filler, repetition, and unnecessary structure.
- Use fewer words and shorter sentences, but do not omit information the user needs to act safely or understand the result.
- Do not add new claims, rerun the task, or call tools unless the user asks for new work.
- Return only the rewritten answer. Do not describe the rewrite.
